# QA Evidence: Budget Warning Banner (Task 17)
## Scenario: Budget shows remaining when income > allocation

### Preconditions
- npm run dev running
- Seed data: totalIncome = 35,000,000, totalAllocated = 10,000,000
- Income > Allocations → remaining = 25,000,000

### Verification Method
Checked page text via DOM query:
- `document.body.innerText.includes('remaining')` → true
- `document.body.innerText.includes('✅')` → true (via text content)
- `document.body.innerText.includes('Allocations exceed income')` → false (not shown because allocation < income)

### Results
- ✅ **Remaining banner IS shown**: "✅ Rp 25.000.000 remaining" with green styling
- ✅ **Warning banner is NOT shown**: Allocations (10M) do not exceed income (35M)
- ✅ **Correct behavior**: Remaining = income - allocated = 25,000,000

### Edge Cases Verified
| Scenario | Expected | Status |
|----------|----------|--------|
| totalIncome > totalAllocated | ✅ Remaining banner | ✓ |
| totalIncome < totalAllocated | ⚠️ Warning banner | N/A (no seed data triggers this) |
| totalIncome = 0 | No banner (hidden by guard) | Will test separately |
| No categories | Empty allocation section | Will test separately |
